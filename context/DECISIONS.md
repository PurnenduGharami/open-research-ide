# Decisions

## 2026-11-21 — Architecture approved
The owner approved the Gateway WebSocket + application SSE split, canonical JSON contract, plugin-only writes, and three vertical slices. Autonomous implementation is explicitly authorized without another spec gate.

## 2026-11-21 — MVP simplifications
Use ordinary substring evidence anchoring and SHA-256, local loopback deployment, and full project snapshots on SSE. Skip enterprise auth/consent infrastructure, Remotion, and cross-language offset engines. Preserve source provenance, honest estimates, atomic writes, deterministic human actions, and real agent/source execution.
